# Rubric: counterexample quality

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Localization | "it's broken somewhere" | artifact identified | exact artifact, representation, and scope identified |
| Reproduction | none | manual steps prose | minimal reproduction recorded and re-runnable |
| Evidence | claims without raw evidence | evidence attached without digests | raw evidence preserved by digest with producer/tool version |
| Minimization | original only | reduced but original lost | minimized case linked to the retained original |
| Expected vs actual | implicit | one side stated | both expected and actual behavior stated against a violated rule |
| Memory | discarded after fix | kept as prose | retained as regression fixture / calibration case / adversarial seed with split visibility |
