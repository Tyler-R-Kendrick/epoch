# Epoch Samples

These samples are small, runnable integrations that demonstrate Epoch concepts
without turning into production applications.

| Sample | Purpose |
|---|---|
| [Hello World CLI](hello-world-cli/README.md) | Barebones command-line app that uses the Epoch Core SDK to create, record, version, and verify a local repository. |
| [Self-Evolving Canvas](self-evolving-canvas/README.md) | Browser agent that renders JSON widgets on an infinite canvas while Epoch stores and gossips runtime history. |
