# Epoch Samples

These samples are small, runnable integrations that demonstrate Epoch concepts
without turning into production applications.

| Sample | Purpose |
|---|---|
| [Hello World CLI](hello-world-cli/README.md) | Barebones command-line app that uses the Epoch Core SDK to create, record, version, and verify a local repository. |
| [Self-Evolving Canvas](self-evolving-canvas/README.md) | Node-backed web app that renders JSON widgets on an infinite canvas while a browser participant gossips local Epoch history with the backend cluster node. |
| [Self-Evolving Dashboard](self-evolving-dashboard/README.md) | Browser-only generated dashboard that stores json-render-shaped component changes as automatically versioned Epoch events. |
