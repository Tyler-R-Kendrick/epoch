# Augment Code

Augment Code is an AI development platform built around a proprietary Context Engine, coding agent, MCP/native tools, and AI-powered code review. It competes with Epoch where teams need agent work to understand large repositories, preserve review rules, and make AI-generated changes trustworthy.

## Competitive Relevance

- Augment's Context Engine is positioned as the differentiator: semantic code search, relationship awareness, commit history, docs, tickets, and tribal knowledge.
- Context Engine MCP makes Augment useful even when another agent, such as Codex, Claude Code, Cursor, Droid, or Gemini CLI, is doing the editing.
- Code Review uses repository guidelines, AGENTS.md, CLAUDE.md, PR summaries, inline comments, and context-heavy review loops.
- Pricing is credit-based across Indie, Standard, Max, and Enterprise plans, with code review and MCP usage drawing from the same usage pool.

## Epoch Implications

- Augment proves that context quality is becoming a standalone competitive surface, not merely an editor feature.
- Its review-guideline model overlaps with Epoch's trust and provenance story: teams want rules to travel with repositories.
- Epoch should treat context retrieval, review evidence, and signed history as one durable loop instead of separate agent, search, and PR-comment systems.

## Unknowns To Track

- Augment's benchmark claims should be rechecked against independent evaluations before using them in customer-facing positioning.
- Credit consumption for context retrieval, review loops, compression, and agent work is a moving target.
