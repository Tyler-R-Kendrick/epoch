# Augment Code Marketing

## Target Customer

Augment targets individual developers, small teams, and enterprises working in complex, multi-repository systems where generic model context is not enough. The strongest pitch is to teams that believe AI coding quality depends on retrieval, architecture understanding, and review precision.

## Positioning

- "Context is the difference" is the core message.
- Augment positions its Context Engine as a cross-agent advantage, not a feature locked to one editor.
- Code Review is positioned around catching real bugs without noisy PR spam.

## Customer Model

- Indie starts at $20 per month with 40,000 credits.
- Standard is $60 per developer per month with 130,000 credits and team features.
- Max is $200 per developer per month with 450,000 credits.
- Enterprise is custom, with custom limits, SSO/OIDC/SCIM, Slack, compliance, support, and security reporting.
- Auto top-ups and shared team credits make usage management part of the buying decision.

## Who It Captures

- Developers frustrated by shallow context in coding agents.
- Teams that want one context layer across several agent tools.
- Organizations that want AI code review tied to repository-specific rules.

## Who It Misses

- Users who want predictable flat-rate usage.
- Teams that prefer open-source or self-hosted context systems.
- Buyers who need signed, repository-native evidence rather than a vendor review comment stream.

## Epoch Opportunity

Augment makes context feel valuable. Epoch should make context and review evidence durable by binding retrieved context, policy, decisions, and accepted changes into signed history objects.
