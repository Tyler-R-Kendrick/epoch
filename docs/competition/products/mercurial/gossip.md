# Gossip

## What People Say

Long-running public comparisons often praise Mercurial as cleaner, more intuitive, and less arcane than Git. The counterpoint is just as common: Git became the default ecosystem, so Mercurial's elegance does not automatically translate into adoption.

## Design And UX Complaints

- Users who like Mercurial often miss its named branches, phases, and simpler mental model after moving to Git.
- Users leaving Mercurial for Git often cite ecosystem pressure more than an isolated Mercurial feature failure.

## Feature Complaints

- Mercurial's forge and collaboration ecosystem is thinner than Git's mainstream hosting network.
- Some public discussion around Firefox's move from Mercurial to Git framed Mercurial workflows as annoying for occasional contributors and Git as the practical default.

## Product Risk For Epoch

Mercurial is the clearest warning that better-feeling VCS primitives can lose to ecosystem gravity. Epoch needs interoperability, migration paths, and visible collaboration wins early, not only a cleaner model.
