# Qodo

Qodo is an AI code quality and review platform that now centers Qodo v2 code review: multi-agent pull-request review, rule enforcement, context-aware feedback, Git integration, and migration from the earlier Qodo Merge / PR-Agent experience. It competes with Epoch around trusted review of AI-generated code and repository rules.

## Competitive Relevance

- Qodo v2 introduced a multi-agent review architecture in February 2026.
- The review flow is Git-native: comments, summaries, rules, and feedback appear directly in pull requests.
- Qodo markets itself around reducing review noise and improving application quality rather than simply generating code.
- Pricing uses credits and plan tiers across individual, team, and enterprise review workflows.

## Epoch Implications

- Qodo proves that teams expect AI-generated code to need AI-assisted review.
- Pull-request comments are useful but can be transient, edited, hidden, or separated from final history.
- Epoch can differentiate by making review findings, rules, and resolution decisions part of signed history.

## Unknowns To Track

- Qodo v1 and v2 names, product surfaces, and PR-Agent migration language have changed quickly.
- Claims about review quality and cost efficiency should be tracked against independent code-review-agent studies.
