# Socket

Socket is a dependency supply-chain security platform focused on proactive package behavior analysis, pull-request checks, malware and typosquat detection, reachability, policy, and developer workflow integrations.

## Competitive Relevance

- Socket competes with Epoch for developer attention during dependency changes and package intake.
- Its PR check model catches risk before vulnerable or malicious packages become normalized in repository history.
- Its package-health and behavior analysis reaches beyond known CVEs into supply-chain risk signals.
- Its reachability claims attack the same alert-fatigue problem that Epoch must avoid when presenting trust evidence.

## Epoch Implications

- Epoch should model dependency-intake events as first-class source-history decisions with actor, review, and policy evidence.
- Epoch can differentiate by preserving repository-native history and materialized-version causality rather than only commenting on PRs.
- Socket shows that package behavior, not just package identity, is becoming central to developer security UX.

## Unknowns To Track

- Socket's strongest reachability and enterprise controls are tied to paid tiers.
- Behavior-based package scoring must balance early detection against false positives and trust in proprietary analysis.
