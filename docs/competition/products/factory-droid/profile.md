# Factory Droid

Factory Droid is an agent-native software development platform with a desktop app, CLI, SDK, local and cloud background agents, Droid Exec for CI automation, Droid Computers, Missions, local code review, Droid Control, agent-readiness analytics, and enterprise deployment controls. It competes with Epoch around governed autonomous development, repository maturity scoring, and enterprise-grade evidence for agent work.

## Competitive Relevance

- Factory frames Droid as a runtime that works across local terminals, apps, SDKs, cloud machines, CI/CD, and enterprise infrastructure.
- The enterprise story includes SSO, SCIM, RBAC, model allow/deny, telemetry, audit logging, data residency, network policy, and airgapped deployment options.
- Agent Readiness makes repository maturity a product surface, which overlaps Epoch's need to explain trust, evidence, and workflow readiness.
- Pricing packages individual agents, cloud computers, usage tracking, and team governance into a clear tier ladder.

## Epoch Implications

- Factory is closer to an enterprise agent operating system than a single coding assistant.
- The product understands that autonomous development adoption depends on controls, telemetry, and readiness, not just model quality.
- Epoch can differentiate by making the repository history itself the durable trust layer rather than relying on a platform control plane.

## Unknowns To Track

- Factory's fast-moving pricing and rolling rate-limit model should be rechecked before quoting exact plan economics.
- Enterprise deployment claims are broad; customer proof and real airgapped operations should be tracked separately from docs.
