# Factory Droid Gossip

## What People Like

- Community users call out the CLI as impressive when Droid can handle real repository work.
- The idea of specialized or orchestrated Droids resonates with users who want planning, coding, review, and product work split across roles.
- Enterprise buyers are likely to appreciate Factory's explicit docs for privacy, data flows, deployment patterns, and audit controls.

## Repeated Complaints

- Prospective users ask whether Factory is meaningfully better than other coding agents, which suggests the market still sees agent platforms as hard to compare.
- The product can sound broad enough to trigger skepticism: "rethought software engineering" claims need concrete workflow proof.
- Rolling limits, extra usage, Droid Core, and managed computers create a richer but more complicated pricing story than a simple subscription.

## Bugs And Friction

- Factory publicly documented abuse of its free trial token path, showing that agent platforms have fraud and cost-control surfaces beyond normal SaaS signup risk.
- Multi-agent orchestration expectations can outpace what users see in day-to-day sessions if coordination is not explicit.
- A platform that runs everywhere also has to explain where data, prompts, telemetry, and model calls go for every deployment mode.

## Epoch Takeaway

Factory is strongest when it acts like an enterprise agent control plane. Epoch should compete by making the underlying code history and agent evidence trustworthy even when a team changes agent platforms later.
