# Marketing

## Target Customers

- Friend groups, gaming communities, creators, student clubs.
- Developer teams and open-source projects that need a hangout + support space outside the forge.

## Positioning

Group chat and communities that feel fun, always-on, and multi-server. For developers, the unspoken position is “where the community actually lives.”

## Customer Model

Free core product; Nitro subscriptions; server boosts; growing enterprise/community monetization.

## Excluded / Weak Fit

- Source-of-truth repository collaboration and signed release provenance.
- Strict enterprise compliance as the primary job (relative to Slack/Teams).
