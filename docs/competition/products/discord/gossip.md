# Gossip

## What People Say

Positive: communities feel alive; easy to spin up a server; channels beat chaotic group DMs; many OSS projects “really live” on Discord.

Skeptical: notification hell; knowledge is siloed and unsearchable; open-source history is lost if the server dies; not a forge; moderation burden.

## Bug And Friction Themes

- Server/channel sprawl.
- Desktop UI density changes (compact vs spacious) still polarizing.
- Important project decisions get trapped in chat scrollback with no signed intent path — exactly where Epoch should win.
