# Marketing

## Target Customers

- Game studios and real-time 3D teams with large binary assets.
- Unity teams that want version control built into Hub, Editor, Dashboard, and Unity Cloud.
- Mixed-discipline teams where artists, designers, and programmers collaborate in one repo.
- Studios that need cloud convenience but may require on-prem hosting for source and assets.
- Unreal or engine-agnostic teams that still need large-file performance and lock workflows.

## Positioning

Unity positions UVCS as VCS made specifically for programmers, artists, and designers facing game-development challenges. The headline benefits are large-file speed, binary handling, centralized and distributed workflows, Smart Locks, Unity Hub setup, cloud or on-prem hosting, and integration across creative tools.

## Customer Model

- Included entry point in Unity Personal for small teams, with user limits.
- Broader UVCS access bundled into paid Unity plans such as Pro and Enterprise.
- Unity Cloud and Dashboard deepen account, organization, storage, permissions, and seat-management ties.
- On-prem options address enterprise control needs while preserving the Unity ecosystem relationship.

## Captured Audiences

- Unity-native studios that want fewer external tools.
- Asset-heavy teams underserved by Git plus LFS alone.
- Producers and leads who need permissions, reviews, locks, history, and dashboard visibility.
- Artists who need file-oriented workflows rather than Git command lines.

## Missed Or Under-Captured Audiences

- General software teams that do not need game asset workflows.
- Open-source communities that prefer forge-native Git hosting and lightweight contributor onboarding.
- Buyers wary of tying repository infrastructure to Unity's broader commercial ecosystem.
- Teams that want cryptographic actor identity, portable event logs, or API-first repository semantics across arbitrary artifact types.
