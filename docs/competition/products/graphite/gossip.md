# Gossip

## What People Say

Graphite is praised when teams already want stacked diffs and need GitHub to support that workflow. The main skepticism is whether teams want another layer on top of GitHub and whether stacked workflows are worth the added vocabulary.

## Bug And Friction Themes

- Graphite docs acknowledge that users can still hit rebase conflicts and then must resolve them in a Git-like conflict state before continuing.
- Authentication, branch naming, stack metadata, and bidirectional GitHub sync are necessary setup concepts before value appears.
- Legacy CLI naming changes in older product tours indicate the workflow vocabulary has evolved and can drift.

## Product Risk For Epoch

Graphite demonstrates that workflow-layer adoption can be easier than replacing storage. Epoch should expose incremental collaboration benefits before asking users to abandon GitHub.
