# Marketing

## Target Customers

- Engineering teams already on GitHub.
- Fast-growing companies with PR review bottlenecks.
- Organizations adopting stacked diffs, merge queues, developer productivity metrics, and AI-assisted review.

## Positioning

Graphite positions itself as the next generation of code review and developer infrastructure for teams that want to ship higher quality code faster.

## Customer Model

SaaS layered on GitHub. The model uses free trial/onboarding to acquire developers and paid team or enterprise plans for review, queue, AI, inbox, and insights workflows.

## Captures

- GitHub teams that want stacked diffs without adopting Gerrit or changing forges.
- Engineering leaders who want metrics and merge throughput.

## Misses

- Teams that reject hosted SaaS or GitHub dependency.
- Users who need offline-first collaboration or cryptographic ownership of review artifacts.
