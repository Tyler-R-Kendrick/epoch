# Graphite

Graphite is a GitHub-integrated code review platform centered on stacked pull requests, PR inbox, merge queue, developer insights, and AI review. It competes with Epoch on collaboration workflow more than storage model.

## Competitive Relevance

- Graphite solves a real GitHub gap: stacked diffs are not first-class in GitHub.
- It monetizes workflow acceleration without asking teams to leave GitHub.
- It is a strong example of how to win adoption by layering on top of incumbent infrastructure.

## Epoch Implications

- Epoch should consider GitHub-adjacent workflow bridges instead of requiring full migration.
- Epoch's intent events and named views could support stack-like incremental review natively if surfaced clearly.
