# Google AI Studio Build

Google AI Studio Build is Google's browser-based full-stack app-building experience, backed by Gemini, Firebase integration, and the Antigravity agent direction. It competes with Epoch by moving prompt-to-app generation, cloud backend setup, preview, publish, and agent handoff into Google's developer ecosystem.

## Competitive Relevance

- Google positions AI Studio Build as a full-stack vibe-coding path for turning prompts into running apps.
- Firebase Studio documentation shows the underlying pattern: app blueprint, generated Next.js app, preview, iterative fixes, Firebase project provisioning, Firestore/Auth/App Hosting, Genkit, and observability.
- Antigravity extends the story toward agent-first development across editor, terminal, browser, asynchronous feedback, artifacts, CLI, SDK, and Google ecosystem integrations.
- Google can capture users already inside Gemini, Firebase, Google Cloud, Android, Drive, Sheets, and Workspace.

## Epoch Implications

- Google is making conversation history, generated app code, cloud project setup, billing activation, and deployment flow part of one AI-assisted development path.
- Epoch can differentiate by independently signing the relationship between prompt, generated blueprint, cloud resources, billing-affecting steps, security rules, tests, and deployed release.
- The migration from Firebase Studio preview toward AI Studio and Antigravity shows why generated app history should be portable outside any one vendor surface.

## Unknowns To Track

- How AI Studio Build, Firebase Studio, and Antigravity converge after the 2026 product changes.
- Whether Google preserves enough audit detail for teams to prove what the agent changed in cloud resources and application code.
