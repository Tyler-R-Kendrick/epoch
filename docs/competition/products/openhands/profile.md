# OpenHands

OpenHands is an open-source, model-agnostic platform for autonomous software-development agents. It offers local OSS usage, a hosted cloud product, enterprise self-hosting, SDK/API surfaces, CLI and web GUI workflows, and GitHub/GitLab/Slack/ticketing integrations for agent work that produces reviewable code changes.

## Competitive Relevance

- OpenHands competes where teams want cloud coding agents but need more control than a proprietary hosted worker provides.
- Its GitHub Action and resolver flow turns issues, labels, comments, and pull requests into a familiar agent delegation loop.
- The public positioning emphasizes secure Docker or Kubernetes runtimes, self-hosting, model choice, enterprise governance, and visibility into agent artifacts.
- It spans product, framework, and infrastructure: individual developers can run it locally, while platform teams can embed or orchestrate it at scale.

## Epoch Implications

- OpenHands validates the demand for transparent, customizable coding agents, but its audit surface is still split across chats, Git provider events, runtime logs, and PRs.
- Epoch can differentiate by making the agent's prompt, context, sandbox state, model choice, command output, policy checks, and accepted diff one signed history object.
- The enterprise self-hosted story raises the bar for Epoch: provenance must work inside private infrastructure without depending on a single SaaS control plane.

## Unknowns To Track

- The product is moving quickly from OSS agent to commercial cloud platform, so pricing, cloud limits, and enterprise capabilities should be rechecked often.
- Public claims around large-codebase orchestration and same-day bug-ticket resolution need customer-specific evidence before being treated as baseline capability.
