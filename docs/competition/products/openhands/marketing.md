# Marketing

## Target Customer

OpenHands markets to individual developers who want an open-source coding agent, platform teams building internal agent workflows, and enterprises that need autonomous code work on private infrastructure. Its strongest customer is a team that wants coding-agent autonomy but does not want to surrender model choice, runtime control, or deployment topology.

## Positioning

- "Build with coding agents, your way" is the core promise: open source, customizable, local or scaled.
- The product positions against chat-first assistants by promising end-to-end engineering work: fix vulnerabilities, review PRs, migrate code, triage incidents, generate tests, and produce reviewable changes.
- The enterprise pitch emphasizes secure isolated environments, self-hosting, BYO LLM, access control, SSO, ticketing integrations, and auditability.

## Customer Model

- Open Source: free local use for a single user and BYO model keys.
- Individual Cloud: free hosted entry point with daily conversation limits and optional provider usage.
- Enterprise: contact-sales self-hosted or private-cloud deployment with multiple users, support, SSO, ticketing, Slack, and platform controls.

## Who They Capture

- Developers who want OSS transparency and model flexibility.
- Platform engineering groups standardizing coding agents across repos.
- Enterprises with security or compliance constraints that exclude purely hosted agents.

## Who They Miss

- Teams that want a turnkey proprietary agent with minimal infrastructure responsibility.
- Small teams that do not want to manage model keys, runtime setup, or GitHub Action configuration.
- Reviewers who need signed, replayable provenance rather than a collection of agent logs and PR artifacts.

## Epoch Opportunity

Epoch should position around evidence continuity: OpenHands can run the work, but Epoch can preserve why the work happened, what the agent saw, which commands ran, and how humans approved the final artifact.
