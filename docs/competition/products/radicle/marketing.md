# Marketing

## Target Customers

- Open source maintainers skeptical of centralized platforms.
- Developers who care about censorship resistance, data ownership, cryptographic identity, and local-first tooling.
- Infrastructure-minded teams willing to operate nodes or seeds.

## Positioning

Radicle positions itself as "the sovereign forge" and an open source peer-to-peer alternative to centralized code hosting.

## Customer Model

Radicle is open source infrastructure. Adoption appears community and ecosystem driven rather than seat-based SaaS. Always-on seed nodes and desktop/web tooling create the path for broader use.

## Captures

- Sovereignty-oriented open source communities.
- Users who want Git compatibility without GitHub dependency.

## Misses

- Mainstream teams that prefer hosted convenience, enterprise governance, and familiar GitHub/GitLab workflows.
- Users who need Windows-first support or do not want to understand node availability.
