# Radicle

Radicle is a sovereign, peer-to-peer code collaboration stack built on Git. It overlaps Epoch strongly on autonomy, cryptographic identity, local-first operation, gossip, and signed collaboration artifacts.

## Competitive Relevance

- Radicle keeps Git as the storage and transfer substrate while adding decentralized identity, peer replication, issues, patches, code review, a node, CLI, TUI, web interface, and desktop client.
- Its Collaborative Objects model is the closest competitive analogue to Epoch's signed intent and policy events.
- Radicle currently wins on having a real decentralized forge product, but Epoch can differentiate with entity-level CRDT behavior and explicit event-log semantics beyond Git.

## Epoch Implications

- Epoch should study Radicle's language around sovereignty, local-first ownership, seed nodes, and signed social artifacts.
- Epoch should be explicit about why its event model is not just "Git plus peer-to-peer forge metadata."
