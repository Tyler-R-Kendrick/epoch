# Forgejo

Forgejo is a community-governed, self-hosted Git forge forked from Gitea and backed prominently by Codeberg. It competes with Epoch where buyers value sovereignty, open governance, federation direction, and lightweight forge ownership.

## Competitive Relevance

- Forgejo provides repositories, pull requests, issue tracking, projects, wiki, package registry, Actions, webhooks, mirrors, and administrative controls.
- Codeberg positions Forgejo as the software layer behind a humane, non-commercial, privacy-friendly alternative to commercial code hosts.
- Federation is a major strategic differentiator, although the Forgejo FAQ still frames it as experimental with moderation and access-control gaps.
- Recent sovereignty narratives, including public-sector Forgejo deployments, strengthen its appeal for organizations reducing dependency on US-controlled platforms.

## Epoch Implications

- Forgejo overlaps with Epoch's sovereignty and ownership language more directly than Gitea does.
- Epoch should explain whether it complements Forgejo federation or offers a separate signed-event substrate for repository evidence.
- Federation roadmaps create user expectations for portable collaboration artifacts; Epoch must be crisp about how signatures, identity, and content addressing travel across tools.
- Forgejo's community trust story is a real competitive asset, not just a feature list.

## Unknowns To Track

- Federation behavior, moderation, domain continuity, and compatibility remain unstable enough to require close monitoring.
- As Forgejo diverges from Gitea, migration and ecosystem compatibility risks may increase.
