# RhodeCode

RhodeCode is an enterprise source code management platform for Git, Mercurial, and Subversion. It competes with Epoch where organizations want unified repository governance, review, permissions, search, and integrations behind the firewall without forcing every legacy repository onto GitHub-style hosting.

## Competitive Relevance

- RhodeCode is deliberately SCM-neutral across Git, Mercurial, and SVN.
- It emphasizes behind-the-firewall deployment, unified access control, repository groups, code review, search, APIs, enterprise authentication, and tool integrations.
- Enterprise Edition adds support, high availability, multi-node scaling, SAML/AD/CAS/OAuth/2FA, and integrations with tools such as Jira, Jenkins, Bamboo, and Slack.
- Its AI code review feature shows that even conservative SCM platforms are adding review automation.

## Epoch Implications

- Epoch should track RhodeCode as a buyer-model competitor: security and legacy migration teams may prefer a governance layer over a new history substrate.
- RhodeCode's strength is pragmatic: one permission and review surface across old and new VCS systems.
- Epoch can differentiate with stronger content-addressed identity, signatures, and history semantics, but must answer the migration and multi-VCS coexistence story.

## Unknowns To Track

- RhodeCode's public community footprint is smaller than GitHub/GitLab/Gitea, so public sentiment is sparse.
- AI review is documented but currently limited; the docs say it can only run once per pull request at the time reviewed.
