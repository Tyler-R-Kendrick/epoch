# Marketing

## Target Customers

- Enterprises with Git, Mercurial, and Subversion repositories that need a shared control plane.
- Security-conscious teams running source code management behind the firewall.
- Organizations that value permissions, repository groups, search, review, auditability, API integrations, and enterprise authentication over social coding features.

## Positioning

RhodeCode positions itself as unified, secure enterprise source code management. The message is that migration from legacy VCS systems is costly, so teams should manage multiple repository types through one secure platform.

## Customer Model

- Community Edition is free and AGPLv3 open source.
- Enterprise is priced per user per year with a minimum seat count and support/SLA.
- Cloud is a dedicated hosted instance model with isolated hardware, SSL, backups, monitoring, and regional placement.

## Captures

- Enterprises with legacy SVN or Mercurial repositories that GitHub-centric products do not serve cleanly.
- Platform teams that want one permission, search, and review model across many repository types.
- Buyers who need commercial support while preserving on-premises or dedicated deployment control.

## Misses

- Open-source communities that want broad network effects, easy sign-up, and familiar GitHub pull requests.
- Small teams that do not need multi-VCS governance or enterprise authentication.
- Developers seeking a visually rich desktop Git workflow rather than an administrative source-control platform.
