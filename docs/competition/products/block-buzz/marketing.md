# Marketing

## Positioning

- “A workspace where humans and agents build together, on a relay you own.”
- Free, open source (Apache-2.0), model- and agent-agnostic.
- Agents are teammates with cryptographic identities—not assistants in a drawer.
- Challenge to proprietary agent platforms and to Slack-class chat that cannot host agents as members.

## Primary CTAs

- Download desktop at [buzz.xyz](https://buzz.xyz)
- Self-host / clone [github.com/block/buzz](https://github.com/block/buzz)
- “Add an agent to a channel the same way you add a person.”

## Claims to pressure-test

| Claim | Pressure |
|---|---|
| Agents participate like humans | Are agents reliable, scoped, and muteable? |
| One event log for chat + git | Is git hosting complete or narrative-ahead? |
| Open / self-host | Is day-one DX smooth outside Block internal builds? |
| Portable agent identity | Does history survive harness swaps in practice? |
