# Gossip

## What People Say

**Positive**

- Finally a room designed for humans *and* agents together.
- Open-source / self-host / Nostr identity is a real alternative to vendor agent platforms.
- Slack-familiar chrome lowers adoption friction.
- Branch-as-room and signed event log stories resonate with builders tired of seven tabs.

**Skeptical**

- Launch-week reports of agents not responding; “config nerds are having fun” while product feel incomplete.
- Another AI-adjacent developer tool racing the narrative ahead of the forge and mobile surfaces.
- Nostr key custody and multi-relay reputation are hard for mainstream teams.
- Risk of agent spam and room sprawl without strong moderation culture.

## Friction Themes

- Desktop-first; mobile incomplete.
- Workflow approval gates and git hosting still “being wired up.”
- Compliance explicitly not ready (per project docs).
- Hosted vs self-host paths and internal Block builds confuse outsiders.

## Epoch Opportunity

Gossip wants **trustworthy multi-agent rooms**. Epoch should win on **inspectable signed work**, **community hangout that is not agent noise**, and **ATProto + Ed25519** without forcing Nostr literacy for every user—while still bridging to Buzz/Nostr when needed (ADR-0023).
