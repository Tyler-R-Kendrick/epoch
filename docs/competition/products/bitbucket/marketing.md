# Marketing

## Target Customers

- Teams already standardized on Jira, Confluence, Compass, and Atlassian identity.
- Small teams that want inexpensive private Git hosting with CI/CD.
- Enterprises that need branch permissions, merge checks, deployment permissions, audit logs, IP allowlisting, and required two-step verification.
- Organizations migrating from Bitbucket Server/Data Center toward Bitbucket Cloud.

## Positioning

Bitbucket positions itself as code and CI/CD powered by the Atlassian Platform. The headline promise is not a new version-control model; it is fewer toolchain gaps between planning, coding, reviewing, building, deploying, and reporting.

## Customer Model

Bitbucket uses per-user SaaS pricing. Current public pricing lists Free for up to five users, Standard at $3.65 per user/month, and Premium at $7.25 per user/month in the United States. Premium carries the governance and AI automation message.

## Captures

- Jira-first development organizations where issue context is central to code review.
- Cost-sensitive teams that want private repos and hosted pipelines without GitLab Premium pricing.
- Engineering managers who want code activity connected to Atlassian planning and reporting.
- Buyers who prefer one enterprise vendor for software delivery collaboration.

## Misses

- Open-source communities and GitHub-native teams that benefit from GitHub network effects.
- Teams that dislike Atlassian account, workspace, and cross-product complexity.
- Developers seeking VCS semantics beyond Git plus pull requests.
- Organizations that need repository evidence to remain independent of a SaaS platform.

## Epoch Lessons

- Epoch should not try to out-Atlassian Atlassian. It should provide durable, signed, portable evidence that can link to Jira and Bitbucket while remaining useful offline and outside the Atlassian tenant.
