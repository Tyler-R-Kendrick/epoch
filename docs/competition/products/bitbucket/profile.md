# Bitbucket

Bitbucket is Atlassian's Git hosting, pull-request, and CI/CD product. It competes with Epoch through team repository collaboration, branch policies, pull requests, merge checks, Pipelines, Jira integration, Rovo/Atlassian Intelligence, and a low-cost cloud pricing model for teams already inside the Atlassian ecosystem.

## Competitive Relevance

- Bitbucket's strongest advantage is distribution through Jira, Confluence, Compass, and the Atlassian Platform.
- Pull requests, Pipelines, branch permissions, merge checks, deployment permissions, and workspace permissions turn Git hosting into a governed team workflow.
- Atlassian Intelligence adds generated PR descriptions, comment editing, Rovo context, and AI integrations around code review.
- Pricing is aggressive for hosted source control: public pricing lists Free for up to five users, Standard, and Premium tiers.
- Data Center remains relevant for large customers migrating from older Atlassian Server deployments or requiring self-managed control.

## Epoch Implications

- Epoch must account for Jira-first teams that choose source-control tooling based on planning and enterprise procurement fit rather than VCS innovation.
- Epoch can differentiate where Bitbucket's repository state is tied to a SaaS workspace: portable signed history, local verification, and content-addressed references should survive outside the Atlassian account.
- Epoch should make it easy to attach durable evidence to Jira/Bitbucket workflows without adopting Bitbucket as the source of truth.

## Unknowns To Track

- Atlassian Intelligence and Rovo capabilities in Bitbucket are evolving quickly, especially around AI code review and cross-product context.
- Public pages describe Bitbucket Data Center as an option, but cloud migration remains a strong Atlassian theme after Server end of support.
