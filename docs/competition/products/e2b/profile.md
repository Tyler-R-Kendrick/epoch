# Profile

E2B provides secure cloud sandboxes for AI agents. It competes with Epoch where product teams need isolated Linux execution, code interpretation, template customization, shell access, MCP tools, and scalable sandbox lifecycle controls for agent-generated code.

## Product Model

- Hosted sandbox platform with JavaScript/TypeScript and Python SDKs.
- Hobby, Pro, and Enterprise tiers with separate usage costs.
- Per-second billing for running sandbox compute.
- Custom CPU, memory, disk, templates, and session length controls.
- Rate limits around concurrent sandboxes and creation rate by plan.
- Docker partnership adds access to Docker MCP Catalog tools through E2B sandboxes.

## Competitive Implication For Epoch

E2B is strongest at making untrusted agent code executable quickly and safely. Epoch can differentiate by turning the execution record into durable repository evidence: sandbox identity, template, commands, MCP tools, network access, produced files, tests, approvals, and commit provenance.
