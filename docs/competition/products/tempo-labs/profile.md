# Tempo Labs Profile

## Product Summary

Tempo Labs is an AI-assisted React app and UI builder focused on design-to-code workflows. It is commonly described as a visual editor for React, with Figma/GitHub-oriented collaboration, PRD or planning steps, component editing, and deployment/export flows aimed at product teams that want better UI quality than prompt-only app builders.

## Competitive Relevance

- Tempo competes less as a generic no-code builder and more as a design-to-React workflow for teams that care about UI structure.
- Its strongest differentiation is planning and visual editing before or during code generation, which addresses a common failure mode of vibe builders: fast first drafts that become hard to maintain.
- GitHub and Figma are core to the buyer story, making Tempo relevant to Epoch's concern with repository-visible collaboration and product evidence.
- The weakness is narrower scope: React/UI focus can miss backend, auth, deployment, and production operations expectations.

## Product Model

- Prompt or PRD-driven generation for React applications and components.
- Visual editor that acts like a design tool while producing code.
- Figma import and design-to-code workflows.
- GitHub-oriented source sync and export.
- Credit-based free tier and higher-priced team/agent tiers reported by third-party pricing trackers.

## Epoch Implications

- Tempo validates that design state and code state are becoming one workflow, not separate handoff artifacts.
- Epoch should treat design-derived changes as provenance-bearing inputs when they affect code, review, or deployment evidence.
- The product category still lacks a clear signed chain from Figma or visual edits to repository commit to runtime verification.
