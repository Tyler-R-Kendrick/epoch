# Devin

Devin is Cognition's autonomous software engineer. It works in hosted development environments with a shell, editor, browser, GitHub integration, pull-request collaboration, code review, skills, and event-driven automations.

## Competitive Relevance

- Devin sells the highest-autonomy version of the AI coding-agent story: assign an engineering task and review the resulting work.
- Its GitHub integration can create pull requests, respond to PR comments, follow Devin-specific PR templates, and use configured commit-signing flows.
- Automations connect Slack, GitHub, Linear, schedules, and custom webhooks to new Devin sessions.
- Skills and environment blueprints create reusable operating procedures for repositories and teams.

## Epoch Implications

- Devin makes "agent as remote engineer" concrete, which raises the bar for auditability, environment provenance, and review receipts.
- Hosted autonomy increases the need to prove exactly which repository state, environment setup, credentials, browser actions, tests, and user comments influenced a change.
- Epoch can compete as the neutral history layer that records agent work regardless of whether the producer is Devin, Copilot, Claude Code, or a human.

## Unknowns To Track

- Pricing and packaging have shifted from early access toward Core, Team, Enterprise, and agent-compute style models; exact public terms should be refreshed before procurement comparisons.
- Enterprise deployment, data retention, custom environment, and commit-signing behavior depend on organization configuration.
