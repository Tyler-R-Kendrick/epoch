# Telegram

Telegram is a **fast consumer messenger** with cloud chats, large groups/channels, bots, and theming. Design-wise it is the simplicity pole opposite Slack: bubbles, one accent blue, almost no workplace chrome.

## Competitive Relevance

- Sets the bar for low-chrome, high-speed messaging feel.
- Shows how far a single accent + content-first layout can go.
- Epoch should steal speed and restraint, not bubble chat semantics.
