# Rork

Rork is a browser-based AI platform for building and publishing mobile apps from natural language. It competes with Epoch where generated software is not just a web prototype, but a native mobile product with app-store packaging, monetization, GitHub sync, and device testing.

## Competitive Relevance

- Rork positions itself around mobile app founders: describe the app, generate the implementation, test on-device, publish to the App Store or Play Store, and monetize.
- The public docs emphasize no local Xcode, Android tooling, or build-pipeline setup for the main builder path.
- Rork's navigation exposes guidance for prompt quality, React Native/Expo versus Swift, RevenueCat paywalls, free trials, privacy policies, app-store publishing, backend, API integrations, GitHub sync, and organic marketing.
- The homepage foregrounds upload limits, founder monetization stories, and app-store outcomes rather than generic component generation.

## Epoch Implications

- Rork shows that AI builders are moving beyond web-app drafts into platform-specific product launch paths.
- Epoch can differentiate by treating generated mobile code, store metadata, privacy/legal artifacts, paywall setup, and release evidence as one auditable history.
- Mobile app generation increases the importance of replayable build and signing records because app-store review and monetization changes are hard to inspect from chat history alone.

## Unknowns To Track

- Rork pricing and Rork Max packaging were not fully exposed in crawlable public pricing content during this run.
- Native build, store-submission, and generated-code ownership details should be rechecked before using Rork in customer-facing claims.
