# Profile

Gitpod is a zero-trust development-environment platform. Gitpod Flex shifted the company from a hosted workspace convenience story toward automated, standardized environments that can run in a customer's cloud, VPC, on-premises infrastructure, or local desktop.

## Product Model

- Hosted management plane plus runners in customer-controlled infrastructure.
- Dev Container and Automations configuration for reproducible environments.
- Gitpod Desktop for local Apple silicon development environments.
- Seat-based enterprise pricing posture with customer infrastructure reuse.
- Security posture built around zero-trust architecture, audit logs, source-code isolation, and secret management.

## Competitive Implication For Epoch

Gitpod competes where teams need reproducible workspaces for human and agentic development. Epoch can differentiate by preserving the causal chain around workspace automation: requested change, environment identity, inputs, commands, generated outputs, test evidence, approval, and commit history.
