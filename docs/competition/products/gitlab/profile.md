# GitLab

GitLab is an all-in-one DevSecOps platform built around Git repository hosting, merge requests, CI/CD, security scanning, planning, compliance, remote workspaces, and AI-assisted SDLC orchestration. It competes with Epoch where repository history becomes the control plane for development workflow, policy, evidence, and team/agent coordination.

## Competitive Relevance

- GitLab owns a complete repository-to-production workflow rather than a narrow VCS layer.
- Merge requests, approval rules, merge trains, pipelines, security reports, and compliance controls make repository events operationally meaningful.
- GitLab Duo Agent Platform and source-code-management messaging now explicitly include teams and AI agents working together.
- Self-managed, SaaS, and Dedicated deployment options let GitLab sell to regulated and enterprise buyers that need governance.
- Remote development workspaces make GitLab more than a forge: the repository can launch a browser-accessible development environment tied to project permissions.

## Epoch Implications

- Epoch should avoid competing only on "better Git history"; GitLab packages history inside review, CI, security, compliance, and planning workflows.
- Signed events and content-addressed storage should be positioned as portable evidence that can feed GitLab-like gates without requiring GitLab as the system of record.
- Epoch can differentiate with local-first, cryptographic, editor-neutral event logs rather than a large Rails/SaaS platform.
- Epoch should make agent-authored work auditable across CLI, SDK, WASM, and forge boundaries, because GitLab is moving AI orchestration into the platform itself.

## Unknowns To Track

- GitLab Duo Agent Platform pricing and included credits are current as of this research pass but may change quickly after broader adoption.
- Public pricing pages expose plan categories and included credits, but large-enterprise contracts, Dedicated pricing, and self-hosted AI model terms require sales engagement.
