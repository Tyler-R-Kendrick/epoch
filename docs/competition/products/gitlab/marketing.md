# Marketing

## Target Customers

- Medium-to-large engineering organizations that want source control, CI/CD, security, compliance, planning, and deployment governance in one platform.
- Regulated buyers that need self-managed or dedicated deployment options.
- Security and platform teams that want guardrails across many repositories.
- Organizations experimenting with AI agents across planning, code review, security analysis, pipeline fixes, and CI/CD modernization.

## Positioning

GitLab positions itself as an intelligent DevSecOps orchestration platform. Source code management is presented as one part of a larger lifecycle: developers and AI agents collaborate in Git repositories, while the platform supplies review analytics, merge trains, CI/CD, remote development, guardrails, and security visibility.

## Customer Model

GitLab uses an open-core and enterprise platform model with Free, Premium, Ultimate, Self-Managed, GitLab.com, and Dedicated options. Current public pricing lists Premium at $29 per user/month billed annually, Ultimate through custom pricing, and GitLab Duo Agent Platform credits included or sold as add-ons.

## Captures

- Enterprises that want one vendor for repository collaboration, CI/CD, security, governance, and planning.
- Teams that value self-hosting or dedicated tenancy but still want a GitHub-class collaboration interface.
- Platform engineering teams that need policy enforcement, auditability, and standardized pipelines.
- Buyers who see AI agents as part of a controlled SDLC rather than a local editor-only tool.

## Misses

- Small teams that find GitLab too broad, expensive, or operationally heavy.
- Developers who want lightweight local-first history and minimal web administration.
- Organizations already standardized on GitHub or Atlassian/Jira workflows.
- Users who want protocol-level innovation rather than a platform around Git.

## Epoch Lessons

- Epoch should target the trust substrate beneath platforms: portable signed events, deterministic local verification, and content-addressed evidence.
- Marketing should explain how Epoch complements GitLab-like governance without forcing teams into a second all-in-one DevSecOps platform.
