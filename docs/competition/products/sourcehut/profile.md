# SourceHut

SourceHut is a suite of open-source software-development tools for Git and Mercurial hosting, mailing lists, patch review, builds, tickets, manual pages, pages, paste hosting, and APIs. It competes with Epoch through a radically minimal, email-friendly, no-JavaScript forge philosophy.

## Competitive Relevance

- SourceHut rejects mainstream forge bloat: no tracking, no advertising, no AI features, and broad functionality without JavaScript.
- It supports Git and Mercurial, appealing to developers who care about VCS plurality and Unix-like composability.
- Builds run virtualized jobs across operating-system images and can integrate with mailing-list patch workflows.
- The hut CLI and GraphQL APIs make SourceHut feel scriptable and exportable rather than trapped in a web dashboard.
- The project is still publicly described as alpha, with beta intended to be feature complete but potentially lacking docs, polish, or bug fixes.

## Epoch Implications

- Epoch should respect the market for fast, textual, low-JavaScript developer tools.
- SourceHut proves that a product can differentiate by removing features mainstream buyers expect.
- Epoch should decide whether email and patch-based workflows are first-class citizens or external integration points.
- Export, backup, and self-hosting stories need to be concrete because SourceHut already markets data control.

## Unknowns To Track

- Production-readiness perception is affected by the long-running alpha label and occasional service incidents.
- The no-AI positioning is directly opposed to agent-heavy repository workflows; this may either exclude or strongly attract different audiences.
