# Cursor Origin

Cursor Origin is an agent-first Git forge — "a git forge for the agentic era" —
announced by Cursor (Anysphere) on 16 June 2026 at its Compile conference. Where
the existing `cursor` dossier covers Cursor's editor and agents, Origin is a
distinct product one layer down the stack: the **hosting, review, and
collaboration substrate** the editor's agents push into. It is the most direct
GitHub replacement in this competition set — it competes with Epoch on the same
ground Epoch was designed for: where durable software history lives, and what
that history has to guarantee when AI agents, not humans, become the primary
authors committing to it.

Origin is built on re-architected technology from **Graphite**, the code-review
startup Anysphere acquired on 19 December 2025 (reportedly above Graphite's
~$290M valuation). It was demoed on stage by Graphite co-founder Tomas Reimers
and announced by Cursor CEO Michael Truell. As of this research it is a
**waitlist-only, pre-launch product** targeting a **fall 2026** release with no
public pricing, no published docs, and no security or data-handling terms.

## What Cursor Claims

- **Agents as primary users.** GitHub's repository model, permissions, and CI/CD
  are "fundamentally optimized for human team workflows"; Origin is built for
  dozens or hundreds of agents that clone, branch, commit, rebase, review each
  other's diffs, and triage CI failures on a single repo simultaneously, in
  seconds.
- **Machine-scale throughput (live demo).** 22.6 commits/second against one
  repository; ~296,000 clones/hour; ~81,000 pushes/hour; global sync latency
  under 400 ms; automatic failover under 10 ms.
- **Architecture.** NVMe-backed Git file servers as the fast path with S3 as the
  source of truth, marketed as supporting "infinite replicas."
- **Git-compatible.** Works with standard Git clients and tooling.
- **API- and MCP-extensible.** Programmatic agent control and CI/CD integration
  over an API and the Model Context Protocol.
- **AI conflict resolution.** An engine that resolves the merge conflicts
  generated by parallel agents "without human intervention in the vast majority
  of cases," plus agentic CI/build-failure auto-fix.
- **Graphite-lineage review.** Stacked pull requests and automated code review
  powered by Cursor's own model inference.

## Competitive Relevance

- Origin is a direct bet that **version-control infrastructure itself must be
  rebuilt for agent-scale, high-frequency, parallel authorship** — the same
  premise behind Epoch. It is the first well-funded incumbent-class competitor
  to say this out loud in a shipping-forge form factor.
- It couples the code editor (Cursor), the review layer (Graphite), the forge
  (Origin), and a proprietary model into one vertically integrated stack,
  contrasting GitHub's horizontal spread. This raises the strategic stakes for
  any neutral, forge-independent history layer.
- Its answer to agent-generated conflicts is a **centralized, proprietary,
  non-deterministic AI merge engine**. Epoch's answer is deterministic replay,
  CRDT-backed conflict-safe entity merging, and signed intent events — a
  structurally different trust model.

## Epoch Implications

- **Validation, not overlap.** Origin confirms the market Epoch targets exists at
  scale, while choosing the opposite architecture: cloud-hosted, closed,
  vendor-custodial. Epoch's local-first, offline-capable, self-hostable,
  forge-neutral posture is the direct counter-position.
- **Provenance is the gap.** Origin makes agents primary authors but has
  published nothing about signed authorship, tamper-evidence, or auditable
  provenance. Epoch's Ed25519 identities, append-only signed intent history, and
  review/test evidence carried in the same history object are precisely what an
  agent-authored forge needs and Origin has not shown.
- **Deterministic vs. opaque merges.** "AI resolves the conflict for you" is a
  convenience that erases why a resolution happened. Epoch should make the merge
  a replayable, signed, inspectable event, not a model's silent decision.
- **Code custody.** Concentrating source, review, model training, and (via the
  reported SpaceX deal) infrastructure under one owner sharpens the
  "who holds my code" question. Epoch's differentiator is history that does not
  require trusting a single vendor to remain durable, portable, or verifiable.
- **Performance bar.** Even if Epoch competes on trust and semantics rather than
  raw ops/sec, Origin's agent-scale clone/push/commit numbers set an expectation
  Epoch's sync and materialization paths should be measured against.

## Unknowns To Track

- No official docs, feature list, roadmap, or blog post accompanied the launch;
  most technical detail comes from the live demo and secondary reporting and
  should be re-verified at GA.
- Pricing, enterprise controls, retention, and data-handling/training-use terms
  are entirely undisclosed — critical before any enterprise or custody comparison.
- The AI conflict-resolution and CI auto-fix guarantees (correctness, override,
  audit trail) are unproven outside a staged demo.
- Strategic context is in flux: SpaceX's reported $60B all-stock acquisition of
  Anysphere (announced 16 June 2026, expected to close Q3 2026) and Cursor's
  reported in-house 1.5-trillion-parameter model change the ownership and
  capability picture behind Origin and should be rechecked.
