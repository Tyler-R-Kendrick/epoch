# Coder

Coder is a self-hosted cloud development environment and AI-agent infrastructure platform. It provisions workspace environments from Terraform templates, connects developers to browser or desktop IDEs, and gives administrators controls for deployment, scheduling, access, audit, observability, and cost.

## Competitive Relevance

- Coder competes with Epoch where teams need controlled, repeatable development environments for contributors and coding agents.
- Its core advantage is operational ownership: infrastructure, templates, network isolation, and policy live with the customer.
- Coder is especially relevant to Epoch's Community sandbox direction because it makes workspace templates and environment inventory a first-class admin surface.

## Product Model

- Open-source core with premium enterprise capabilities.
- Self-hosted deployment across cloud, Kubernetes, Docker, OpenShift, or air-gapped environments.
- Terraform-defined templates with starter templates and GitOps management.
- Integrations for VS Code, JetBrains, Cursor, Windsurf, Dev Containers, Backstage, and agent workflows.

## Epoch Implications

- Epoch should assume sophisticated buyers already understand template-backed workspaces and will ask what signed history Epoch adds.
- Coder's admin screenshots show that environment inventory, scheduling, and audit views are expected product surfaces, not backend-only concerns.
- Epoch can differentiate by binding workspace templates, agent actions, review outcomes, and repository history into a portable provenance layer.
