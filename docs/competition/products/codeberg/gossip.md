# Gossip

## What People Say

Public discussion often praises Codeberg as a principled GitHub alternative with a friendlier governance model. The common counterpoint is pragmatic: GitHub still has more contributors, integrations, CI ecosystem depth, and default visibility.

## Bug And Friction Themes

- Community issue trackers and social updates show recurring operational concerns such as abuse handling, service capacity, spam, and platform policy decisions.
- Users considering migration worry about discoverability and contributor friction when projects leave GitHub's network.
- Because Codeberg uses Forgejo, some complaints map to Forgejo feature gaps rather than Codeberg-specific product choices.

## Product Risk For Epoch

Codeberg can capture values-led open-source users before they consider a new repository model. For many maintainers, aligned governance plus familiar Git is enough.

## Opportunity For Epoch

Epoch can complement a platform like Codeberg by adding verifiable history, signatures, and portable repository evidence without asking maintainers to abandon community-hosted workflows.
