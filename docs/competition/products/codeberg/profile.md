# Codeberg

Codeberg is a nonprofit, community-oriented code hosting platform built on Forgejo. It competes less as a new VCS and more as a values-led hosted forge for open-source projects that want Git hosting, issues, pull requests, packages, pages, and CI-adjacent workflows without GitHub ownership or advertising pressure.

## Competitive Relevance

- Codeberg packages Forgejo into a public community destination, solving discovery and hosting for projects that do not want to self-host.
- It competes with Epoch's community platform story by making "ethical hosted forge" the central product promise.
- Donation-backed operations and association governance are part of the product identity, not only background legal structure.
- Because it is based on Git and Forgejo, it keeps contributor workflows familiar.

## Epoch Implications

- Epoch should separate community trust from storage trust. Codeberg earns trust through governance and nonprofit positioning; Epoch can earn additional trust through signed repository history.
- A hosted Epoch community experience would need a strong values and operations story, not just technical advantages.
- Codeberg's existence means Epoch cannot assume self-hosted sovereignty is enough; many open-source maintainers want hosted convenience with aligned governance.

## Unknowns To Track

- Capacity, moderation policy, and feature availability can change as Codeberg grows.
- Codeberg's competitive surface inherits Forgejo capabilities and limitations, so material Forgejo changes can alter Codeberg's position quickly.
