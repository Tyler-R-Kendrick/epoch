# Anything Create Profile

## Product Summary

Anything, formerly Create/Create.xyz, is an AI app builder for turning natural-language prompts into websites, web apps, mobile apps, databases, authentication, integrations, and published apps. It combines chat generation, version history, project settings, deployment, code export on paid plans, and higher-tier autonomous or testing features.

## Competitive Relevance

- Anything competes for broad "describe an app and ship it" demand across web and mobile, with more emphasis on end-to-end app creation than component generation.
- Its docs explicitly describe pages, components, functions, databases, user accounts, assets, AI modes, secrets, auth providers, SEO/social settings, publish, export, and credits.
- The Max tier's automated testing and visual QA claims are especially relevant to Epoch because they turn app-builder reliability into a productized proof surface.
- Public complaints around credits, rebrand/migration friction, bugs, and cancellation/refund trust show the category risk when generation feels nondeterministic.

## Product Model

- Free credit-based plan with publish and AI integrations.
- Paid plans add private projects, branding removal, custom domains, code export, higher credits, and advanced agents.
- Builder interface combines chat, canvas, preview, project settings, and deploy.
- Published apps can use AI integrations that consume credits.

## Epoch Implications

- Anything shows that AI builders are moving toward generated tests and visual QA as part of the product, not just developer add-ons.
- Epoch should treat generated tests as evidence only if their scope, inputs, and results are auditable.
- The credit model creates a strong need for "what changed and why" history so users do not pay repeatedly to repair opaque regressions.
