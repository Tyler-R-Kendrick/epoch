# Magic Patterns

Magic Patterns is an AI design and prototyping tool for product teams. It competes with Epoch where product discovery, design-system context, customer feedback, and engineering handoff need to become durable software intent before implementation starts.

## Competitive Relevance

- Magic Patterns generates UI prototypes from ideas, screenshots, redesign prompts, templates, and Figma inputs.
- It emphasizes matching existing product UI, importing design systems, real-time multiplayer collaboration, password-protected previews, published URLs, custom domains, and engineering handoff.
- The docs call out product managers, designers, engineers, marketers, sales teams, and website builders as distinct users.
- Security and enterprise readiness are marketed with SOC 2 and ISO 27001 claims.

## Epoch Implications

- Magic Patterns demonstrates that competitive pressure is not only code generation; it is also AI-generated product intent and design exploration.
- Epoch can differentiate by linking prototype decisions to signed implementation history, acceptance scenarios, and downstream code changes.
- The MCP and engineering-handoff story is strategically relevant because design tools are trying to become live context providers for coding agents.

## Unknowns To Track

- The precise generated-code export and roundtrip behavior should be rechecked before comparing to source-control or SDK features.
- Public pricing is summarized on the homepage, but operational credit and usage details should be reverified before quoting.
