# OpenAI Codex

OpenAI Codex is a multi-surface coding agent spanning the Codex desktop app, CLI, IDE extension, web/cloud tasks, GitHub code review, skills, and automation-oriented workflows. It competes with Epoch where agent-authored changes need durable history, evidence, review, and bounded execution across local and cloud environments.

## Competitive Relevance

- Codex positions the desktop app as a command center for supervising multiple coding agents in parallel.
- Codex supports isolated worktrees, cloud tasks, local CLI sessions, IDE use, and GitHub pull-request review.
- OpenAI now prices Codex through token-based credits for most plans, making agent work a measurable operating cost rather than a simple seat entitlement.
- The product foregrounds sandboxing, approvals, logs, and permission boundaries as core safety affordances.

## Epoch Implications

- Codex normalizes parallel agent work as a first-class software development workflow.
- Worktree isolation and task logs are useful, but Epoch can differentiate by making agent history signed, content-addressed, replayable, and independent of one vendor's agent UI.
- Codex's credit model makes evidence efficiency matter: Epoch should help teams understand which agent-produced changes are worth preserving, reviewing, and reusing.

## Unknowns To Track

- Codex pricing, model availability, and rate limits changed materially in April 2026 and should be rechecked before customer comparisons.
- Cloud task retention, enterprise audit export, and code-review policy surfaces are evolving quickly.
