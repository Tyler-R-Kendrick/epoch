# Gossip

## What People Say

Sapling's public story is strongest where users already feel Git is too hard to reason about. Smartlog is broadly compelling because it names a real pain: developers lack a clear mental picture of repository state.

## Bug And Friction Themes

- The public docs note that the Sapling server and virtual filesystem are not yet available publicly, limiting the externally reproducible scale story.
- Adoption requires teams to accept a different command vocabulary and workflow even though Git concepts remain familiar.

## Product Risk For Epoch

Sapling shows that a better graph/status view can be a core product differentiator. Epoch needs an equally strong view over event frontier, named views, pending intents, merged policy, and sync state.
