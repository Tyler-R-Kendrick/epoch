# Gossip

## What People Say

Public complaints often separate GitHub's power from its approachability. A recurring theme is that GitHub is optimized for programmers and can be confusing for people who only want to download or inspect a project.

## Design And UX Complaints

- Repository pages expose too many developer-specific concepts at once.
- Casual users may not know that the green Code button is the source download/clone entry.
- Help often assumes Git literacy, which reinforces the feeling that the interface is hostile to beginners.

## Product Risk For Epoch

GitHub's weakness is not capability; it is cognitive load. Epoch can win attention if it explains repository state, identity, sync, and review in simpler terms without hiding expert detail.
