# Marketing

## Target Customers

- Individual developers and open source maintainers.
- Startups and enterprise engineering organizations.
- Platform teams that want source hosting, CI/CD, security scanning, code review, package hosting, AI coding, and governance in one ecosystem.

## Positioning

GitHub positions itself as the default home for software creation. The pitch is broad: host code, collaborate, automate, secure, and ship from one platform.

## Customer Model

- Free individual and open source usage drives network effects.
- Paid team and enterprise tiers monetize private repos, governance, security, Copilot, Actions capacity, and support.

## Captures

- Teams that value ecosystem gravity and integrations more than sovereignty.
- Users who need GitHub-native CI, review, and social proof.

## Misses

- Teams that require peer-to-peer collaboration, offline review, cryptographic autonomy, or local-first operation.
- Users overwhelmed by Git/GitHub conceptual load.
