# Amazon Q Developer

Amazon Q Developer is AWS's AI assistant for software teams working across IDEs, the command line, AWS console surfaces, GitHub, and AWS application modernization. It competes with Epoch when teams want agent-authored code, code review, and transformation evidence to stay close to identity, billing, and cloud governance.

## Competitive Relevance

- Q Developer combines code completions, chat, security scans, code review, `/q dev` GitHub issue-to-PR workflows, and Java upgrade transformations.
- The GitHub app gives AWS a low-friction way to enter non-AWS repositories through automatic PR review and issue-triggered development.
- The Pro subscription adds administration, higher limits, and pooled transformation capacity while retaining a perpetual free tier for lighter users.
- Java transformation gives Q Developer a modernization story that pure coding agents often lack.

## Epoch Implications

- AWS is teaching enterprises that coding agents are part of cloud governance, not only editor productivity.
- Epoch can differentiate by making Q-generated plans, diffs, reviews, and transformation summaries signed and repository-native instead of scattered across IDE chat, GitHub comments, AWS billing, and transformation artifacts.
- Q's GitHub preview makes agent-originated pull requests normal, increasing the need for independent provenance and acceptance records.

## Unknowns To Track

- GitHub integration limits, supported repositories, and preview terms should be rechecked before customer-facing comparisons.
- Q Developer is closely tied to AWS identity and billing, which may change as Kiro, Q, and AWS developer tooling converge.
