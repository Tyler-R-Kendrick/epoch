# Marketing

## Target Customer

Bolt.new targets developers, founders, students, designers, and non-technical builders who want a working web app quickly in the browser. It also appeals to JavaScript developers who understand StackBlitz and want an AI layer over a real runnable workspace.

## Positioning

- Bolt positions itself around full-stack web development in the browser, not just code suggestions.
- The product contrasts itself with tools that cannot install packages, run backends, or edit and execute real project files.
- StackBlitz and WebContainers give Bolt a technical credibility story for browser-native development.
- The open-source repository positions Bolt as both a product and an agent framework reference.

## Customer Model

- Free usage supports trials until daily AI limits are reached.
- Paid plans are tied to higher usage capacity and continued AI interactions.
- StackBlitz account and project infrastructure connect Bolt to a broader browser IDE ecosystem.

## Who They Capture

- Users who want the fastest possible route from prompt to interactive preview.
- JavaScript teams that want to avoid local environment setup for experiments.
- Developers who value code visibility more than black-box no-code generation.

## Who They Miss

- Teams that need deterministic Git history, signed approvals, and repeatable CI evidence before accepting generated changes.
- Builders whose apps grow beyond browser runtime comfort or token-budget predictability.
- Customers who need stable enterprise governance around repository sync, secrets, and deployment approvals.
