# Databutton

Databutton is an AI app developer platform for building full-stack apps with React frontends and Python FastAPI backends. It plans, researches, writes app code, manages secrets, supports data-source and package integrations, exposes code editor access, provides checkpoints, deploys apps, and sells human expert support tiers for serious projects.

## Competitive Relevance

- Databutton competes with Epoch around AI-generated app plans, code, checkpoints, deployment, and human-assisted delivery.
- It positions the agent as an app developer rather than only a code assistant.
- The React plus FastAPI stack gives generated work a clearer technical shape than many no-code tools.
- Pricing packages AI-only usage with community support, dedicated human support, and high-touch human advisor services.

## Epoch Implications

- Databutton shows that customers may buy a hybrid AI plus human delivery model when pure self-serve app generation feels risky.
- Epoch can differentiate by proving what the AI and the human expert each changed, tested, deployed, and restored.
- Checkpoints and deployment restore controls are useful primitives, but they need signed file, data, secret, and runtime evidence.

## Unknowns To Track

- Databutton docs still describe some behavior in broad terms, so current GitHub/export, hosting, and production controls should be checked before hard comparisons.
- Human support tiers may change the product economics substantially compared with credit-only builders.
