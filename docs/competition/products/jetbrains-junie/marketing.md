# Marketing

## Target Customer

Junie targets JetBrains IDE users who want a coding agent without leaving the project model, inspections, and keyboard workflows they already rely on. It also targets teams that prefer a single commercial IDE vendor to assemble AI chat, agent work, provider routing, MCP, and project guidelines.

## Positioning

- JetBrains positions Junie as the coding agent that works with the developer's preferred model and existing IDE.
- The landing page emphasizes low migration friction, benchmark cost efficiency, advanced planning, human-in-the-loop control, remote monitoring, persistent guidelines, and skills.
- The broader JetBrains AI subscription story packages Junie with AI Assistant rather than making users buy a completely separate product.

## Customer Model

- Individual users can start with free/BYOK-style usage or paid JetBrains AI subscriptions.
- Paid tiers use AI credits and top-ups, with Ultimate positioned as the regular Junie usage tier.
- Organizations can buy into the JetBrains AI and IDE Services model for centralized governance, enterprise controls, and model-provider choices.

## Who They Capture

- Existing JetBrains loyalists who do not want to move to VS Code forks for AI.
- JVM, backend, and large-project developers who value IDE project intelligence.
- Teams that want model flexibility but still prefer a governed vendor relationship.

## Who They Miss

- Developers who want a simple terminal-only agent with transparent pass-through usage.
- Windows/WSL-heavy users blocked by platform limitations.
- Teams that need vendor-neutral signed provenance rather than IDE-local checkpoints and chat history.
