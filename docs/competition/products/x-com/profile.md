# X (x.com)

X is a **public short-form timeline** product (formerly Twitter). Design competition is about scan density, action-row grammar, and extreme contrast — not repository workflow.

## Competitive Relevance

- Defines the modern "post + action icons + counts" feed grammar.
- Hairline separators and pure black/white set a sleekness bar users compare against any feed UI.
- Epoch should match scan discipline while keeping signed work identity, not viral metrics.
