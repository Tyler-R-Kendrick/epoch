# Figma Make

Figma Make is Figma's design-native prompt-to-code and AI app-building surface. It turns prompts, frames, design systems, Make kits, code context, external connector data, and Supabase-backed data into functional prototypes or web apps that can be edited, tested, published, and shared from inside the Figma product suite.

## Competitive Relevance

- Figma Make competes with Epoch around design-to-code intent, functional prototypes, app publishing, and external-tool context.
- It starts from the design canvas rather than the repository, which gives designers and product managers a lower-friction path to working software.
- Make kits connect npm packages, variables, styles, and written guidelines so generated apps can follow a team design system.
- MCP connectors bring Notion, Asana, Linear, GitHub, Atlassian, and custom internal tools into the generation context.

## Epoch Implications

- Figma Make proves that product intent is moving upstream into design files and connector-backed prompts before code review starts.
- Epoch can differentiate by signing the relationship among source frames, Make kits, connector fetches, generated code, published settings, and later engineering commits.
- Design-native app generation creates a new provenance gap: teams need to know which visual decisions and external data shaped the code.

## Unknowns To Track

- Figma Make's model selector, credit consumption, GitHub-local-code workflow, and connector permissions are changing quickly.
- Supabase-backed app claims and publish settings should be reverified before compliance or production-readiness comparisons.
