# Tabnine

Tabnine is an enterprise-controlled AI coding platform that has moved beyond autocomplete into IDE agents, CLI workflows, code review, private deployment options, and an Enterprise Context Engine. It competes with Epoch where teams want code assistance to respect private code, organizational patterns, and governance boundaries.

## Competitive Relevance

- Tabnine's core message is control: private deployment, zero retention, no training on customer code, and enterprise compliance.
- The Context Engine indexes connected repositories and generates higher-level architectural context that agents can use through IDE and CLI workflows.
- Tabnine Agent performs multi-step edits, test generation, refactoring, documentation synthesis, and policy validation inside developer environments.
- The CLI adds terminal-native review, automation, remote code search, custom commands, and headless usage.

## Epoch Implications

- Tabnine validates the idea that context and governance are now more differentiated than generic code generation.
- Epoch can complement or compete by making the output of any context engine signed, portable, and reviewable as project history.
- Tabnine's enterprise posture raises the bar for privacy claims; Epoch should be precise about code retention, model training boundaries, and exportable evidence.

## Unknowns To Track

- Tabnine's public packaging has shifted toward enterprise tiers; free or individual plan availability should be rechecked before comparisons.
- Context Engine setup and agentic preprocessing are evolving quickly and may change in admin flows or included tiers.
