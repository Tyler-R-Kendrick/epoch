# Sourcegraph Amp Marketing

## Target Customer

Amp targets developers and teams who want a powerful CLI/editor coding agent, are comfortable paying for frontier-model usage, and value extensibility over a polished all-in-one IDE. Sourcegraph also positions code search and enterprise code intelligence around teams with complex codebases.

## Positioning

- "Frontier coding agent for your terminal and editor" is the core claim.
- Amp emphasizes multi-model routing, strong opinions, threads, skills, subagents, MCP, permissions, plugins, and SDK access.
- Sourcegraph's broader pricing connects Amp to enterprise code understanding, search, navigation, MCP, APIs, Batch Changes, and governance.

## Customer Model

- Individual Amp usage is framed around credits and at-cost pricing.
- Teams add team billing and no-training guarantees.
- Enterprise adds SSO, zero LLM retention, support, and workspace controls.
- Sourcegraph enterprise code search starts at a much larger annual platform purchase, creating a ladder from individual agent to enterprise code intelligence.

## Who It Captures

- Developers who want terminal-native agent power and do not want another full editor.
- Teams that value threads and shareable agent context.
- Platform engineers who want to extend the agent with local tools, plugins, and SDK workflows.

## Who It Misses

- Users who want a predictable flat monthly agent allowance.
- Developers who prefer visual checkpoint workflows and guided branch publication.
- Enterprises that need agent history represented directly in Git-like project records rather than external shared threads.

## Epoch Opportunity

Amp is making agent sessions collaborative. Epoch should make the accepted outcome of those sessions durable by linking prompt context, tools, diffs, approvals, and resulting snapshots in signed repository history.
