# Sourcegraph Amp

Sourcegraph Amp is a frontier coding agent for the terminal and editor, built around threads, multi-model routing, agent modes, AGENTS.md, skills, subagents, MCP, plugins, permissions, CLI execution, SDKs, and shared workspaces. It competes with Epoch around agent thread history, collaborative coding evidence, and the durability of autonomous change context.

## Competitive Relevance

- Amp treats model choice as an implementation detail and routes work across frontier, fast, and second-opinion models.
- Threads can be saved, shared, referenced, and governed through workspace visibility controls.
- Plugins, toolboxes, MCP, skills, subagents, Oracle, Librarian, Painter, code review, and permissions make Amp highly extensible.
- Pricing emphasizes at-cost or credit-based agent use rather than a simple flat subscription.

## Epoch Implications

- Amp's thread model is close to a lightweight agent history system, but it still lives in the vendor tool.
- Shared threads and workspace controls prove that agent conversations are becoming team artifacts.
- Epoch can differentiate by turning accepted agent work into verifiable repository history instead of tool-specific conversation history.

## Unknowns To Track

- Amp's model mix, free tier, and exact pricing mechanics have changed quickly and should be verified before firm comparisons.
- Enterprise retention, thread visibility, and security controls should be checked against the current manual before regulated-customer claims.
