# GitHub Copilot Code Review Marketing

## Target Customer

GitHub targets teams already using GitHub pull requests, Actions, branch protection, code scanning, and Copilot subscriptions. The strongest fit is an organization that wants AI review without evaluating another vendor or teaching developers a new review surface.

## Positioning

- GitHub positions Copilot Code Review as structured, actionable feedback at the moment a pull request opens.
- The broader Copilot story bundles code completion, chat, coding agent, review, security, and enterprise controls into one GitHub-native AI layer.
- Billing positions advanced model usage and code review as usage-based AI Credits, with Actions minutes for the agentic infrastructure.

## Customer Model

- Individual, Business, and Enterprise Copilot customers receive included AI Credits allowances depending on plan.
- Organizations and enterprises can pool credits, set budgets, and pay for additional usage.
- Code review also consumes GitHub Actions minutes, so teams already buying Actions capacity are the natural buyers.

## Who They Capture

- GitHub-first teams that prefer default platform features over specialized review tools.
- Enterprises that want procurement and governance through existing GitHub contracts.
- Developers who want AI review in the same place as human PR review.

## Who They Miss

- Teams that need multi-forge review portability.
- Cost-sensitive users who prefer BYOK or fixed review pricing.
- Organizations that want review evidence independent of GitHub billing, hidden model routing, and Actions execution.
