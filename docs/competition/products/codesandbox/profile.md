# CodeSandbox

CodeSandbox is a browser development and programmable sandbox platform. Its current competitive surface includes collaborative browser sandboxes, VM-backed development environments, instant cloning, hibernation, snapshots, Git persistence, and the CodeSandbox SDK for AI agents, code interpretation, evals, CI, and scaled sandbox creation.

## Competitive Relevance

- CodeSandbox competes with Epoch where a contributor or agent needs an isolated, resumable code environment with shareable live preview.
- Its SDK reframes sandboxes as programmable infrastructure for AI systems, not only a web IDE.
- The Together AI partnership positions CodeSandbox as code execution infrastructure for generative AI products.

## Product Model

- Browser and VM-backed sandboxes for individual developers, teams, education, design systems, and AI agents.
- SDK/API access for creating, forking, hibernating, resuming, and connecting to isolated sandboxes.
- Git-backed persistence and memory snapshots for fast resume.
- Usage in CI/CD, secure code interpretation, evals, and parallel agent experiments.

## Epoch Implications

- Epoch should assume programmable sandboxes will become common infrastructure for coding agents.
- CodeSandbox's instant fork and snapshot model raises user expectations for reversible, branch-like environment history.
- Epoch can differentiate by making the sandbox's decisions, accepted changes, and provenance portable beyond CodeSandbox's infrastructure.
