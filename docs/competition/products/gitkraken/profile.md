# GitKraken

GitKraken is a commercial Git productivity platform spanning GitKraken Desktop, GitLens, CLI, browser surfaces, workspaces, Launchpad, AI features, and GitKraken MCP. It competes with Epoch on developer-facing history comprehension and daily workflow control rather than on replacing Git storage.

## Competitive Relevance

- GitKraken makes the repository graph, branch state, PR status, issues, and multi-repository work visible in polished desktop and IDE surfaces.
- Launchpad turns pull requests, issues, builds, reviewers, WIP, and sprint filters into a single operational dashboard across GitHub, GitLab, Bitbucket, Azure DevOps, Jira, and Trello.
- Workspaces are a strong onboarding and coordination primitive: a team can share a known set of repositories and act across them with bulk clone, fetch, pull, and open flows.
- GitKraken's current positioning folds Git UI, GitLens, AI, MCP, code suggestions, cloud patches, and DORA-style insight into one "DevEx platform" story.

## Epoch Implications

- Epoch should assume that users expect history and review state to be visible, not just correct. GitKraken sets the bar for approachable graph navigation and branch operations.
- Epoch's signed, content-addressed, portable history can differentiate only if it is paired with equally clear day-to-day workflow surfaces.
- GitKraken also shows the risk of adding cloud collaboration around a local VCS: privacy, plan gating, and cloud dependency become part of user trust.

## Unknowns To Track

- GitKraken's AI and MCP surfaces are changing quickly; plan boundaries and privacy controls may shift.
- GitKraken has on-premise offerings, but Team Launchpad and Cloud Workspaces have environment-specific limitations that matter for regulated teams.
