# Ellipsis

Ellipsis is a GitHub-native AI teammate that automatically reviews code, enforces style guides, answers repository questions, writes release notes, creates implementation plans, and can generate tested pull requests from issues, Slack messages, or PR comments. It competes with Epoch around lightweight AI review and repair inside normal GitHub collaboration.

## Competitive Relevance

- Ellipsis emphasizes fast review on every commit of every pull request, with confidence-scored comments and quiet-mode controls.
- The product learns from thumbs-up, thumbs-down, and replies, then applies team feedback to future reviews.
- Rules can be entered manually, inferred from prior comments, or extracted from repository style-guide files.
- Code generation runs in a Docker container and can compile, test, and return a PR or commit.

## Epoch Implications

- Ellipsis demonstrates demand for a smaller, more approachable AI teammate than full IDE or cloud-agent platforms.
- Its no-rogue-commits and side-PR claims align with Epoch's concern for explicit human approval and reviewable change boundaries.
- Epoch can differentiate by binding rules, feedback, generated fixes, and review outcomes to signed repository history.
