# Roo Code

## Summary

Roo Code was an AI coding suite spanning a local VS Code extension, cloud execution, and routing. As of the current docs snapshot, all Roo Code products were scheduled to shut down on May 15, 2026, with unused-balance refunds and alternatives recommended. Even with that discontinuity, it is competitively useful because it packaged modes, MCP extensions, checkpoints, codebase indexing, todos, terminal control, and model/provider configuration into a highly customizable agent workflow.

## Product Model

- VS Code extension for local IDE workflows.
- Cloud and router products before the May 15, 2026 shutdown.
- Modes for roles such as Code, Ask, Architect, Debug, Orchestrator, and custom team-defined assistants.
- Marketplace for MCPs and modes, with project and global installation scopes.
- Checkpoints, todo lists, codebase indexing, filesystem edits, terminal commands, and MCP tool access.

## Competitive Differentiation

Roo Code differentiated through customizable agent roles and tool permissions. Rather than forcing one assistant personality, it made mode configuration part of the workflow and let teams assign models, instructions, and allowed tools per mode.

## Epoch Implications

- Epoch should preserve the idea of role-scoped capabilities, but bind them to signed provenance and repository policies.
- Roo's shutdown shows that product continuity is a competitive dimension for developer infrastructure.
- The mode and MCP marketplace concept is powerful, but Epoch should make trust, installation scope, and permission boundaries easier to audit.
