# Slack

Slack is the default **channel-based workplace messenger**. Teams organize into workspaces and channels, with threads, search, apps, huddles, and canvas docs layered on top. The product defines the modern "rail + channel + composer" collaboration grammar that Community Web is competing with for *feel*, not feature parity.

## Competitive Relevance

- Channel-first navigation is the mental model users already bring to project collaboration.
- Sticky composer + hover actions set the bar for "this feels like a real product."
- Density, unread, and place-selection patterns are table stakes for all-day tools.
- Epoch differs by signed intents, repository-linked work, and trust metadata — not chat history as source of truth.
