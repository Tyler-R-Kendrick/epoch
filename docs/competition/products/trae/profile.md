# Trae

## Summary

Trae is an AI-native development environment from ByteDance that combines an IDE, SOLO agent mode, builder workflows, browser, terminal, documentation view, connectors, and mobile access. Its competitive pressure on Epoch is the claim that an agent can become the center of the entire product-development workspace rather than a sidecar inside an editor.

## Product Model

- AI-first IDE and SOLO product suite.
- SOLO Builder for idea-to-web-application flows, including requirement analysis, PRD generation, code generation, preview, and deployment support.
- SOLO Coder for deeper project iteration, bug fixing, architecture refactoring, and multi-agent orchestration.
- Membership tiers moved toward token-based pricing in 2026, with Lite, Pro, Pro+, and Ultra plans described by Trae.
- As of May 2026, Trae announced open SOLO Desktop, Web, and Mobile availability with tiered usage across the product suite.

## Competitive Differentiation

Trae differentiates by making the agent workspace visual and multi-surface: task panel, chat, editor, terminal, docs, browser, Figma, connectors, and mobile dispatch. The product story moves from "AI inside tools" to "tools inside the AI."

## Epoch Implications

- Epoch should watch Trae's visual supervision model: users want to see planning, execution, browser output, and code state together.
- Epoch can differentiate through transparent provenance, local trust boundaries, and repository evidence where Trae sentiment is weaker around data transparency.
- Trae's product breadth creates a UX risk: as modes, plans, and agent roles multiply, the user can lose confidence about cost, model choice, and what the agent is actually doing.
