# Marketing

## Target Customer

Claude Code targets developers and teams who want Anthropic's strongest coding models inside practical engineering workflows: terminal, IDE, desktop, and GitHub. It appeals especially to senior engineers comfortable supervising an agent through local tools.

## Positioning

- Anthropic positions Claude Code as an agentic coding partner that can read a repo, edit files, run commands, and handle multi-step tasks.
- The desktop product pushes beyond CLI into parallel sessions, previews, connectors, PR monitoring, and visual diff review.
- GitHub Actions support positions Claude as a participant in issue and PR workflows.

## Customer Model

- Individual and team access ties to Anthropic account plans, Claude subscriptions, API usage, and organization controls.
- The product captures both interactive local usage and automated hosted workflows.
- Enterprise adoption depends on policy for local command execution, data access, connectors, and CI permissions.

## Who They Capture

- Power users who prefer terminal control over editor-only AI.
- Teams that want high-quality reasoning across large refactors, debugging, reviews, and test loops.
- Developers who already trust Claude for analysis and want it closer to the repository.

## Who They Miss

- Teams that need deterministic, vendor-neutral provenance independent of the agent transcript.
- Users who want predictable fixed-cost coding assistance rather than rate-limit or usage-sensitive sessions.
- Organizations that cannot permit local agents to run commands or access broad repository context.
