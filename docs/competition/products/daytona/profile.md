# Profile

Daytona is secure infrastructure for running AI-generated code. It competes with Epoch where users need isolated, elastic execution for agents that install packages, run servers, manipulate files, execute code, and operate GUI environments.

## Product Model

- Hosted sandbox API, SDKs, CLI, and dashboard.
- Usage-based pricing with free compute credits, per-second CPU, memory, storage, GPU, and Windows OS charges.
- Stateful sandbox lifecycle with running, stopped, archived, deleted, snapshot, fork, and restore concepts.
- Computer Use API for mouse, keyboard, screenshot, recording, display, and accessibility operations in Linux sandboxes, with Windows and macOS support in private alpha.
- Dashboard controls for activity, resource limits, spending analytics, webhooks, and organization usage.

## Competitive Implication For Epoch

Daytona's strength is runtime elasticity for agents. Epoch can differentiate by preserving what the agent did inside those sandboxes as signed, content-addressed evidence: code changes, command history, environment identity, snapshots, resource use, approvals, and resulting commits.
