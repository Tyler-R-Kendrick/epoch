On OpenUI

OpenUI Lang is a streaming-first DSL for model-generated UI. Its library is defined at build time and only the 49KB parser ships, because the runtime takes a JSON schema rather than Zod. The model streams openui-lang; the parser yields a tree at every chunk, which is why the view appears as it is written.
