# Nightboard navigation and projection parity

This evidence maps stable object identity, mounted projections, explicit reply
topology, deterministic navigation, saved views, route restoration, shared
actions, and APG interaction behavior to executable checks. The JSON manifest
contains no hand-authored pass state: its verifier finds each acceptance ID in
tracked executable tests and fails closed when a claim or proof disappears.

Run:

```bash
npm run nightboard:parity
```

The focused command is part of `npm run verify`. Browser behavior remains the
authority for focus, history, interaction layers, live anchors, and responsive
operation; unit and contract checks own pure identity, graph, projection,
query, persistence, and authorization invariants. Screenshots and recordings
may aid human review but are never the sole proof.

Primary patterns are paraphrased in the manifest from Plan 9 namespaces and
`nntpfs`, RFC 5322, Atom, AT Protocol, ActivityStreams, Newsboat, zoxide, fzf,
the HTML History API, and WAI-ARIA APG feed, tree view, combobox, and keyboard
interface guidance.

The required persona review and concrete fixes are recorded in the
[adversarial critique](adversarial-critique.md).
