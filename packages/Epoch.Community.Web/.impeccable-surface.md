# Community Web surface brief

Operate-mode community board. **This is the committed Community visual world**
([ADR-0027](../../docs/design-decisions/0027-community-visual-world.md)).

Impeccable critique, audit, polish, live, and design iteration for Epoch
Community should target this directory until `Epoch.Community.Web` reaches
Community Web parity.

Primary persona: GitHub open-source contributor / citizen builder who already
reads terminal chrome. Keyboard-first is non-negotiable.

The Persuade marketing entry is a separate surface (`index.html` /
[`.impeccable-surface-landing.md`](.impeccable-surface-landing.md)). Brand click
on this board returns there; do not treat the logo as Following-home.
