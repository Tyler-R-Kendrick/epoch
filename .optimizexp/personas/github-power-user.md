# GitHub power user — Contribution graph & forge baseline

## Who I am

I am a **GitHub** power user: repos, issues, PRs, Actions, discussions, org identity, and the **dashboard contribution feed**. GitHub is where code "lives" in my muscle memory. I also bounce to Discord/Slack because GitHub is weak as a hangout.

- Contribution-typed feed events (ships, PRs, releases, issues) on Epoch's network home.

## Constraints

- Do not compete only as "another host"; compete on offline, signed intent, community hangout, ATProto discovery.
