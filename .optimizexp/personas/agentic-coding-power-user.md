## Goals

- See agent intent, permissions, commands, edits, tests, reviews, and checkpoints as durable signed history.
- Delegate in parallel without losing ownership, isolation, or merge topology.
- Recover a session after interruption without rereading an entire transcript.

## Constraints

- Agent confidence is not evidence; claims need replayable artifacts and independent gates.
- Model/provider choice changes cost and risk but should not fragment repository identity.
- Permissions and external side effects require explicit scope and audit.

## Accessibility & inclusion needs

- Long agent traces need summaries, landmarks, and searchable structured events.
- Approval prompts need keyboard operation, plain language, and persistent context.
- Status must not rely on animation, color, or rapid transient notifications.

## Success looks like

- I can answer who asked, what the agent understood, what it changed, what proved it, and how to undo it.
- Epoch history outlives vendor-specific checkpoints and chat retention.

## Failure modes I hate

- “Done” with no diff, test evidence, unresolved review threads, or side-effect record.
- Hidden model routing, silent permission expansion, or unrecoverable cloud state.
- Context split across chat, IDE, forge, and runner with no durable join key.

## Review instructions

Write bus expect before agent actions and act/outcome after evidence capture.
